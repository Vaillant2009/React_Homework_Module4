Домашні завдання з React — Модуль 4

У папці є чотири окремі проєкти:
task1-city — інформація про місто, функціональні компоненти.
task2-city — інформація про місто, класові компоненти.
task3-book — інформація про книгу, функціональні компоненти.
task4-book — інформація про книгу, класові компоненти.

У кожному проєкті файли лежать без додаткових вкладених папок:
App.jsx, App.css, main.jsx, index.html, package.json.

Як запустити:
1. Відкрийте потрібну папку task... у Visual Studio Code.
2. Відкрийте термінал у цій папці.
3. Виконайте: npm install
4. Виконайте: npm run dev
5. Відкрийте адресу, яку покаже Vite (зазвичай http://localhost:5173).

Примітка: для відображення фотографій та обкладинки потрібне підключення до Інтернету.
